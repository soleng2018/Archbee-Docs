# Overview

The Nile Cloud Radius integration with Microsoft Intune is a mandatory step if Intune is to be used in the Radius policies. The integration setup consists of the following steps:

- Create a new App registration in Entra ID with appropriate Intune and Microsoft Graph permissions
- Copy and Paste the Tenant ID, Client ID and Secret from the newly created Entra ID App

# Requirements

- Entra ID user with roles to create new application registrations, add Microsoft Graph and Intune API permissions and grant those permisions to the app registration
- Administrator access to the Nile Control Center (Nile Portal)

# Configuration

The integration of cloud Radius with Microsoft Intune consists of the following tasks:

1. Create a new app registration and collect the following parameters:
   - Application (client) ID
   - Directory (tenant) ID
   - Client secret
2. Add the appropriate API read permissions to Microsoft Graph and Intune
3. Login to Nile Control Center and fill up the Intune configuration using the parameters collected from the app registration

## Entra ID App registration

- Sign in to Microsoft Entra ID portal: :Link[https://entra.microsoft.com]{href="https://entra.microsoft.com" newTab="true" hasDisabledNofollow="false"}
- In the left pane, expand the Entra ID menu option, and click "**App registrations**"
- In the **App registrations** window, select **New registration**

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/ChHJve_JcjEEYcG4Ov7dL_intune-new-registration1.png" size="74" width="777" height="258" position="flex-start" darkWidth="777" darkHeight="258" showCaption="false"></Image>

- On the **Register an application** page, type the **Name** and click the **Register** button

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/abT62NpQtzgRPOzGg_RM7_intune-new-registration2.png" size="74" width="770" height="847" position="flex-start" darkWidth="770" darkHeight="847" showCaption="false"></Image>

- Save the **Application (client) ID** and the **Directory (tenant) ID** to a text editor to copy and paste on the Nile Control Center Intune configuration page
- In the left pane, click on **Certificates & secrets** to generate a secret key

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/T0yIvWXt3Xl_BcYpYTqkz_intune-registration3.png" size="74" width="695" height="454" position="flex-start" darkWidth="695" darkHeight="454" showCaption="false"></Image>

- Click on **New client secret** to add a client secret
  In the pop up window, enter a description and select the expiration period, then click the **Add** button

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/2w0cw69ue8pooQ7OlYdSL_intune-secret.png" size="74" width="670" height="189" position="flex-start" darkWidth="670" darkHeight="189" showCaption="false"></Image>

- Save the **Value** to a text editor to copy and paste on the Nile Control Center Intune configuration page

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/lza54TkZoxE1kaBXLum6W_intune-secret2.png" size="74" width="1056" height="241" position="flex-start" darkWidth="1056" darkHeight="241" showCaption="false"></Image>

- In the left pane, click **API permissions** to access the permissions page

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/BOZJoL_gggYfM26_-_hHd_intune-api-permissions1.png" size="74" width="1103" height="525" position="flex-start" darkWidth="1103" darkHeight="525" showCaption="false"></Image>

- Click the **Add a permission** button to start adding read API permissions to the Nile cloud as a client one by one as per the following list

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/TUw8z_nb4tSOrDW9QfIu4_intune-api-permissions2.png" size="74" width="1023" height="428" position="flex-start" darkWidth="1023" darkHeight="428" showCaption="false"></Image>

- Once all listed permissions are added, click the **Grant admin consent for Default Directory** button to apply the admin consent to all permissions

## Nile Intune Configuration

- Login to Nile Control Center at [https://www.nile-global.cloud](https://www.nile-global.cloud)&#x20;
- Navigate to **GLOBAL SETTINGS > Identity**, and select the **Intune Configuration** page

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/dLrpJVEGMvrn71APmGCNM_cleo-intune.png" size="74" width="904" height="489" position="flex-start" darkWidth="904" darkHeight="489" showCaption="false"></Image>

- Fill up the **Provider Tenant ID**, **Client ID** and **Secret** with the information saved earlier when creating the Entra ID app registration, and click the **SAVE** button&#x20;

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/thvgiOC-icw8cvaDCnd5K_screenshot-2025-11-18-at-114508aam.png" size="74" width="652" height="350" position="flex-start" darkWidth="652" darkHeight="350" showCaption="false"></Image>

- Once the configuration has been saved, click the TEST button to validate the Intune connection

<Image src="https://app.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/ta91uCR8qEGwyN2O5xnfr_screenshot-2025-11-18-at-114834aam.png" size="74" width="651" height="360" position="flex-start" darkWidth="651" darkHeight="360" showCaption="false"></Image>
