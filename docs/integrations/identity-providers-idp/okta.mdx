This document covers the setup of SAML (Security Assertion Markup Language) federation between Nile (Okta) as a Service Provider (SP) and Okta as Identity Provider (IdP), for the purpose of leveraging Nile wired and wireless SSO.

# Requirements

- Administrator rights to the Nile Portal.
- Administrator rights to Okta.
- The same Nile Portal administrator needs to be an Okta user.

# Configure

## Okta Groups

- Sign-in to Okta portal
- Navigate to **Directory > Groups&#x20;**&#x6F;n the side menu
- Click on **Add group&#x20;**&#x74;o add a new group ‘NileAdmin’

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/_l1DcQ8n7OGBKxYVvNOT-_image.png" size="80" width="1014" height="232" position="center" darkWidth="1014" darkHeight="232" showCaption="false"></Image>

- Similarly, add another group called ‘NileMonitor’

## Okta People

- Navigate to **Directory > People** on the side menu
- Click on **Add person&#x20;**&#x74;o add a new user

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/IGVI9pedKgVv18-XsNP1__image.png" size="80" width="1014" height="264" position="center" darkWidth="1014" darkHeight="264" showCaption="false"></Image>

- Add a person as illustrated

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/IeFMKIEeO5R1AkymZ0F9Q_image.png" size="80" width="484" height="566" position="center" darkWidth="484" darkHeight="566" showCaption="false"></Image>

- Edit the person’s profile and add their mobile number, as it is a Nile SSO requirement that Okta users pass the following non-empty attributes to Nile via SAML:
  first name, last name, email and mobile phone
- Assign that person to the ‘NileAdmin’ group, only if a Nile Portal admin access is desired.

## Nile Portal Identity Provider Setup

- Log in to the Nile Portal with the same Okta administrator at https\://www\.nile-global.cloud
- Navigate to **GLOBAL SETTINGS** -> **Identity** to access the **Providers** page
- Click on **ADD A NEW PROVIDER** to start configuring Okta as an IdP

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/lMWby0BRBdn93HUhtgyT4_screenshot-2025-04-09-at-93907-am.png" size="80" width="849" height="509" position="center" showCaption="false"></Image>

- Fill out the 'Add a new provider' form from the Okta data saved in the previous step:
  &#x20;   **IdP Issuer URI**:     \<Identity Provider Issuer>
  &#x20;   **IdP SSO URL**:       \<Identity Provider Single Sogn-On URL>
  &#x20;   **Destination URL**: \<Identity Provider Single Sogn-On URL>
  &#x20;   **IdP Certificate**:    Copy and paste the contents of the X.509 certificate previously downloaded

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/GVAB_QPm8NKRjYG2b9bbT_image.png" size="80" width="496" height="418" position="center" showCaption="false"></Image>

- Click **SUBMIT** button to complete adding Okta as an IdP provider

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/AR6yNyjrmLXV1zHxzXw80_image.png" size="80" width="770" height="452" position="center" showCaption="false"></Image>

- Click on the **METADATA** button to download the xml metadata file
- Open the downloaded metadata file with a text editor and collect the **entityID** and **Location**
  Their values will be used to replace the dummy parameters in the Okta app and complete its setup.

  For illustration purposes, here is an example of such parameters:
  &#x20;   *entityID:     https\://www\.okta.com/saml2/service-provider/sptticcpcztszhxuqqqs*&#xA;*&#x20;   Location:   https\://dev-344858.okta.com/sso/saml2/0oa1iwzz0gkku6ndn358*

## Second pass at the Okta app Setup

- Log in back to the Okta portal
- Open the ‘Nile -Okta-SAML-app’
- In the **General** tab, scroll down to the **SAML Settings** section and click the **Edit** button
- In **General Settings&#x20;**&#x73;ection, click **Next**
- In **Configure SAML&#x20;**&#x73;ection, replace the dummy entries as follows:&#xA;**&#x20;      Single Sign On URL**: \<Nile Portal **Location**>
  &#x20;     Check off the option to ‘**Use this for Recipient URL and Destination URL**’&#xA;**&#x20;     Audience URI**: \<Nile Portal **entityID**>
- Scroll down to the bottom of the page and click **Next**
- In the **Feedback** section, click **Finish** to complete editing the Okta SAML app

# PSK-SSO SSID Setup

- Login to Nile Portal URL: [https://www.nile-global.cloud](https://www.nile-global.cloud)
- Go to **NETWORK SETUP -> Segments** tab page to create the PSK SSO Segment:
- Click on the '+' to add a new segment
- Type a meaningful segment name (Demo PSK SSO)

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/SGgqBDOOBNwrh2TZpVAx7_image.png" size="80" width="654" height="214" position="center" showCaption="false"></Image>

- Click the **Service area&#x20;**&#x74;ab and click on **SELECT SERVICE AREAS&#x20;**&#x74;o select the appropriate site and/or building, then click **OK** to continue

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/QAQbAk20yUH34d4Y62v0B_image.png" size="80" width="654" height="394" position="center" showCaption="false"></Image>

- Select the DHCP server and Subnet:

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/-uStqTYBIB0AlLv5vngyP_image.png" size="80" width="646" height="262" position="center" showCaption="false"></Image>

- Click the SAVE button to complete the addition of the new segment
- Go to the **NETWORK SETUP -> Wireless** page to create the PSK SSO SSID
- Click on the '+' to add a new SSID

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/YmmaxYyqa11s1AogKrR0F_image.png" size="80" width="894" height="456" position="center" showCaption="false"></Image>

- Select the following:&#xA;**&#x20;   Type**: Personal (radio button)&#xA;**&#x20;   Name**: Type the desired SSID name&#xA;**&#x20;   Security**: Select WPA2 from pull-down list&#xA;**&#x20;   Enable SSO**: Click checkbox to Checked&#xA;**&#x20;   Passkey**: Enter the Pre-shared key&#xA;**&#x20;   Segments:&#x20;**&#x53;elect the previously created Demo-PSK-SSO segment from the pull-down list
- Click the **SAVE** button to complete the PSK-SSO SSID creation.
