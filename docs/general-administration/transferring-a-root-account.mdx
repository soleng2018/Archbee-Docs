Root account is created when customer/tenant gets on boarded. Root user is the first user for customer that gets added to system. There could be only one root account for customer, so there could be a need to change root account user in situations where a person is leaving the organization or change in roles.

To transfer a root account, navigate to Account Management >> Profile >> Transfer Root Account.

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/4zxKQgU70Ey_VRDLNt-Fs_transfer-root-dark-1.png" darkSrc="https://archbee-image-uploads.s3.amazonaws.com/6swSwg1BT-BlfEPtYJhxM/_hEbb7COUms_ozh46Iy9R_transfer-root-light-1.png" size="100" width="3456" height="1536" darkWidth="3452" darkHeight="1520" position="center" showCaption="false"></Image>

Select one of the admins to transfer the root account privileage.

<Image src="https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/bUA4R6GUWLw1UiFi16o5K_transfer-root-dark-2.png" darkSrc="https://archbee-image-uploads.s3.amazonaws.com/6swSwg1BT-BlfEPtYJhxM/sGlhje2F8pp1XXArr8KGh_transfer-root-light-2.png" size="100" width="3454" height="1498" darkWidth="3454" darkHeight="1516" position="center" showCaption="false"></Image>

After clicking "Next" the current root admin will receive an OTP and once that is entered, the root account privileges are transferred.
