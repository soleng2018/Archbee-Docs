## Overview

Once the user signs up for the Nile service, they will get root user privileges. There is only one root user per enterprise. Once the root user gets access, they can start creating admin access for other users in their company. Currently, there are two types of roles available: Administrator and Monitor.

## Configuring Administrators

<hint type="info">
  If you are adding administrators from other domains, you will need to allow that domain first. Please refer to the :Link[allowed domain]{href="https://docs.nilesecure.com/allowed-domains" newTab="true" hasDisabledNofollow="false"} page for more info.
</hint>



1. Login into the Nile Portal and click on the "Network Setup" tab from the left side navigation pane. Click on Users.
2. Click on the "+" sign on the left-hand side corner.
3. Enter the email address, full name, country code, and phone number of the person.
4. Select the appropriate group from the drop-down list:&#x20;
   - **Administrator**: This role will have complete read and write access to the Nile Portal. Persons designated with this role can also create more admins as needed.
   - **Monitor**: This role will have read-only access to the Nile portal. Persons designated with this role will not be able to change any configuration or create any admins.
   - **Helpdesk:&#x20;**&#x54;his role will have read-only access to the Nile portal along with the authority to approve wired devices through the access management page.&#x20;
   - **Installer:&#x20;**&#x54;his role empowers administrators to onboard technicians as installers. By assuming the installer role, a technician gains the capability to be assigned tasks related to installation, cabling, and site discovery. Additionally, they can utilize the Nile Nav app to activate devices effectively.
5. Click "Save". The newly created admin should now get an email with the instructions to sign up.
