## Overview

Nile secures wired network access by requiring every device connected to a Nile switch to be authenticated before it can access the network. Wired authentication is always enabled and cannot be disabled.

You can configure one or more authentication methods based on your device types and security requirements. Once authenticated, each device is assigned to a network segment according to your configuration.
