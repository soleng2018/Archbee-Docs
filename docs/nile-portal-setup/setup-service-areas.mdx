# Overview

Service Areas are locations where you need Nile Network-as-a-Service (NaaS).

## Configuring a New Service Area

1. Log in to the Nile Portal. In the left navigation, select **Network Setup > Service Areas**.
2. Click the '+' sign to start adding a site.
   - **Name:** Define the site location where you need the Nile service.
   - **Find my address:** Enter the exact shipping address where Nile will deliver its network elements.
3. Click the newly created service area and add all buildings within that service area. Enter the information for each building where you need the Nile service, and click **Save**.
   - **Note:** If some buildings do not have unique addresses, you can drop a pin on the map for reference.
4. Select the newly defined building and add all floors in that building. Attach the floor plan to each floor.
   - **Optional:** After adding floor plans, you can define Wi‑Fi zones on the floors, if applicable. Wi‑Fi zones are custom SSID zones used to serve a specific set of clients.
