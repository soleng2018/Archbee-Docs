## How to check top network users by Mac address, SSID, and Segment

Login to the Nile Portal at [https://u1.nile-global.cloud/](https://u1.nile-global.cloud/).

Select the Summary dashboard from the left hand menu.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/zsmpKtlyZaCz8D-zsGb9m_uehx6gq1p2jeznmorfig4m5ywzcs2lk-yg.png)

Select the desired scope and SSID you want to examinefrom the drop down menu.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/XWXFSEzc5mVwZhnKIF809_arnshgwkx4m06nt7lhknn3rdefbffdea4g.png)

## Search for a specific device

Scroll down and enter the MAC address of the respective device in the search button
