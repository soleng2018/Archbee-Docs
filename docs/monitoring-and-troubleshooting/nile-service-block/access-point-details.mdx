## Overview

The Nile Access Service provides a detailed Access Point (AP) management and monitoring interface within the Nile Portal. This feature enables IT administrators and network managers to efficiently oversee, troubleshoot, and maintain their wireless network infrastructure. By offering comprehensive AP information, the Nile Portal enhances network visibility, simplifies troubleshooting, and improves overall network management.

## Accessing AP Details

- Navigate to the "Device" page in the Nile Portal.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/0f6E-ix5RFGATlkbznwUQ_image.png)

- Click on any "Wireless Device" to view its details.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/GHzwvwIZChcGoVBz2-n6V_image.png)

- Scroll down to the Heat Map section.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/WINs7iqIpkLWaRqHFSi_D_image.png)

- Click on "Access Point" to see its details.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/2WD4fA0HmwR1VNwha8kuY_image.png)

### Quick Tooltip Information

Hover over an AP icon to view a quick tooltip with basic information. The tooltip provides at-a-glance:Comment[ information about an AP:]{docCommentId="r__BdhE6CydC3yMyVQO_L" resolved="true"}

- AP Name
- Serial Number
- AP Status (color-coded for online/offline)
- Band Channel
- Channel Utilization Per Band (percentage)

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/UdO2FPMju1CvIKb8DhEqf_image.png)

### Detailed AP Information

Clicking on an AP icon reveals a comprehensive set of details:

| Attribute                    | Description                                             |
| ---------------------------- | ------------------------------------------------------- |
| AP Status                    | Online or Offline status (color-coded)                  |
| AP Name                      | Designated name of the AP                               |
| Serial Number                | Unique identifier for the AP                            |
| Up Time                      | Operational duration (format: XX days YY hrs ZZ mins)   |
| SW Version                   | Current AP software version                             |
| Last Reboot Reason           | Cause of the most recent AP restart                     |
| Last Reboot Time             | Timestamp of the last reboot                            |
| Last Seen                    | Timestamp of the last seen                              |
| Location                     | Location of the AP                                      |
| Link Speed                   | Up link Speed of the AP                                 |
| Switch Name                  | Switch Name with which the AP is connected to.          |
| Switch Port                  | Switch Port with which the AP is connected to.          |
| Serial Number                | Switch Serial Number with which the AP is connected to. |
| Open Alerts                  | Open Alerts corresponding to the AP.                    |
| Band Channel                 | Assigned channel for each radio                         |
| Channel Utilization Per Band | Percentage of channel usage per radio                   |
| Transmit Power of Radios     | Power output per radio (in dBm)                         |

## :Comment[Viewing All APs]{docCommentId="fhTw4P8h2uIKOEy3t79cA" resolved="true"}

To access a comprehensive view of all APs:

- Open the detailed slide-in panel for any AP.
- Click the "See All APs" option at the bottom of the panel.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/xoweczXYPGJ2UrCW8OmaO_image.png)

- A new page will open, displaying detailed information for all APs.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/fRdn0oPTMGpvlNsc2DxkV_image.png)

- For easier navigation, one can select **Site**, **Building**, or **Floor** to view the AP details specific to that location.
- To see details of any particular AP, click on that AP.

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/09uFirvYHNQilCPkMiH8w_image.png)

## Benefits of AP Management and Monitoring

1. **Enhanced Troubleshooting**: Quickly identify and diagnose issues related to specific APs or areas of the network.
2. **Improved Network Visibility**: Gain a comprehensive view of the wireless infrastructure's status and performance.
3. **Efficient Management**: Easily track firmware versions, uptime, and connected devices across all APs.
4. **Proactive Maintenance**: Monitor channel utilization and transmit power to optimize network performance.
5. **Simplified Auditing**: Access detailed information about AP configurations and status for compliance and reporting purposes.

## Summary

By leveraging the AP Management and Monitoring feature in the Nile Portal, administrators can ensure optimal wireless network performance, quickly address issues, and maintain a high-quality user experience across their Nile Access Service deployment.
