The Nile Device Inventory page gives you a snapshot of all the Nile Elements (NEs) that are deployed across your organization globally.

This will give you an understanding of how the core networking elements are functioning and other details such as:

- Uptime of the device
- Software version that is running on the device
- System Temperature
- Connected Ports
- Nile Switches connected downstream.
- Nile Access Points connected to the switch.
- PoE Capacity
  - PoE Requested
  - PoE Granted
  - PoE Available
- Radio Information for APs
  - Channels operating on and the Utilization %

This page can be filtered further based on the Service Areas, Device Status and the Device types.

To access this page, please navigate to Account Management >> Nile Device Inventory
