The wireless client's current location and roaming histories can be verified in the Events info

1\. Login to the Nile Portal [https://u1.nile-global.cloud/](https://u1.nile-global.cloud/)

Enter the user name as the user email address and Password.

2\. Navigate to the Device tab->Select the specific wireless client or use the search bar filter using MAC OUI -> Click on the client -> Scroll down to the bottom of the page right after the Floor Plan information:
