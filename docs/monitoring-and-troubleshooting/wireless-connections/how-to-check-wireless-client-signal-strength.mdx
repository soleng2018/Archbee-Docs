From Nile Portal Wireless Device details, we could see the history of Client connection as well as graphs of Signal Strength during time range:

![Nile Portal: Client signal info](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/7hukTnT04gbOnVs054UEm_jvzfdg4y54vmgjoy1qeo7fkaprradfvnmw.png "Nile Portal: Client signal info")

Additionally, you could run RUN TEST from Client details page:

![Nile portal: Run test](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/UkO38zrTXdB7C_KV8gQT1_zxv1o6lgkzyqbhjxxbv8zhdonxbamiezyq.png "Nile portal: Run test")

After running RUN TEST, we could see pop up window with detailed information about current connection status that includes:

- Signal
- Ping
- ARP Ping
- AQI
- Coverage
- DNS
- DHCP
- Radius
- Internet
