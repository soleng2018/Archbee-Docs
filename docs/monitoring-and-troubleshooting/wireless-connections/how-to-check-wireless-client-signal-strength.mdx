From the Nile Portal Wireless Device details, you can see the history of Client connection as well as graphs of Signal Strength during the time range:

![Nile Portal: Client signal info](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/7hukTnT04gbOnVs054UEm_jvzfdg4y54vmgjoy1qeo7fkaprradfvnmw.png "Nile Portal: Client signal info")

Additionally, you can run RUN TEST from the Client details page:

![Nile portal: Run test](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/UkO38zrTXdB7C_KV8gQT1_zxv1o6lgkzyqbhjxxbv8zhdonxbamiezyq.png "Nile portal: Run test")

After running RUN TEST, you can see a pop-up window with detailed information about the current connection status that includes:

- Signal
- Ping
- ARP Ping
- AQI
- Coverage
- DNS
- DHCP
- RADIUS
- Internet

![Nile portal: Run test](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/HvDJLy0Y9Ppjcu5uEIohs_whdqvvba3wicif4wylnd6yzbh5rg4rbzdq.png "Nile portal: Run test")
