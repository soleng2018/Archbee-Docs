As Nile, we collect client activities as Events that could be used to check the status and history logs.

To search the history of Events, you need to navigate to Nile Portal Device details.

You can select a time range for logs you want to check on the upper right corner.

Events and status histogram shows \ details when events happened and client status for that time. In the example below, you can see that during the last two hours there were 3 successful connections:

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/6APEwdLL5zzRL5eTjR3_x_gj7m-4fri00kfaz68cmgps7mr-1qa4i76q.png)

If you click one of those connection events, you can see the Events table only for that particular connection. The example below shows that the latest connection had 4 events that show Client connection, dot1x authentication and DHCP address assignment:
