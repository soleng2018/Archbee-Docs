As Nile we collect client activities as Events that could be used to check the status and history logs.

To search the history of Events we need to navigate to Nile Portal Device details.

We could select time range for logs we want to check on right up corner.

Events and status histogram will show \ details when events happened and client status for that time. In example below we could see that during last two hours there were 3 successful connection:

![](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/6APEwdLL5zzRL5eTjR3_x_gj7m-4fri00kfaz68cmgps7mr-1qa4i76q.png)

If we click to one of those connection events, we could see Events table only for that particular connection. Example below shows that latest connection had 4 events that shows Client connection, dot1x authentication and DHCP address assignment:

![Nile Portal: Events  ](https://api.archbee.com/api/optimize/6swSwg1BT-BlfEPtYJhxM/gigOuNW1S2FS90alIN21m_qj-gqa3hl1w3vl-f8hnflxbqhw-bhsbkcq.png "Nile Portal: Events  ")
