# Overview

Every flow observed by the Zero Trust Fabric is evaluated and the resulting action is logged into a centralized policy log, visible in Nile Control Center. The information recorded in the log includes:

When no policy exists for a given source/destination pair, the default-deny posture of the Zero Trust Fabric will deny traffic by default.  The policy log will record this as a Deny action but will not identify the source and destination information.  If explicit logging of the default Deny behavior for a source/destination pair is needed, then an explicit Deny policy should be created.
