URL filtering, also known as web filtering, enables organizations to control and monitor the websites and web content that users can access on the Nile Guest Service network.&#x20;

URL filtering works by comparing requested web addresses (URLs) against a predefined list or database of categorized websites. Based on the configured policies, the filtering system can then allow, block, or restrict access to specific web resources.

Nile Guest Service uses common categories such as news, gambling, adult material, malicious, dangerous etc to classify websites and apply the appropriate access controls.&#x20;

The administrator can apply granular policies for URL filtering.  &#x20;

- ****:Comment[**Strict**]{docCommentId="4XlfiQrHUM92QUQTfSYXN" resolved="true"} - Blocks everything in "Moderate" along with other potentially harmful sites.
- **Moderate** - Blocks everything in "Low" and adult sites.
- **Low&#x20;**- Blocks online threats including malware & spyware sites.
- **None -** Allows full web access with no filtering or restrictions applied.
