As customers continue to use the Nile Access Service and its AI-powered visibility apps, we've listened to their feedback and enhanced security plus boosted efficiency. A major update to the Nile Trust Service introduces a new security feature that now authenticates wired devices with the same methods used for wireless devices. Many customers have adopted Single Sign-On (SSO) with multi-factor authentication for wireless network access, providing a simpler alternative to the complexities of certificate management and RADIUS server deployment. We've extended SSO to wired access as well, delivering a unified authentication experience that ensures consistent user connectivity across both wired and wireless networks.

Additionally, we're improving our alerting and notification system. To combat alert fatigue and provide more detailed insights for resolving real issues during help desk incidents, we’re rolling out three key enhancements. These updates are designed to help customers troubleshoot more efficiently—one of the core advantages of our campus network-as-a-service offering.
