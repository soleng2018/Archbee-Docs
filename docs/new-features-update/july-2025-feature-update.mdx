        *Seamless Integration of Nile Trust Service with Palo Alto Prisma (SSE)*
      </Paragraph>
    </td>
    <td>
      Nile now supports seamless integration with **Palo Alto Networks Prisma SSE**, enabling direct traffic forwarding from the **Nile Service Block (NSB)** to Prisma for cloud-delivered security inspection—without requiring external routers or manual tunnel configuration.
      <Paragraph>
        Administrators simply enter Prisma account credentials into the **Nile Control Center**, and Nile automates the entire process—establishing secure, resilient IPSec tunnels and managing SSE connectivity as a service.
      </Paragraph>
      <Paragraph>
        Traffic steering is policy-based, allowing selective forwarding to Prisma SSE based on segment. For example, organizations can exclude guest traffic from inspection to optimize cost and performance.
      </Paragraph>
      <Paragraph>
        The integration is built on Nile’s resilient architecture, with automatic failover to ensure continuous, secure access.
      </Paragraph>
    </td>
    <td>
      As organizations move toward universal Zero Trust—encompassing every user (employee, guest, contractor) and every device (IT, OT, IoT), whether remote or on-site—they require consistent SSE policy enforcement across all access scenarios. This integration enables exactly that: applying Prisma SSE policies not only to remote users, but also to traffic originating from office-based users and devices.
      <Paragraph>
        Key Benefits
      </Paragraph>
      <Paragraph>
        **Consistent Policy Enforcement:&#x20;**&#x45;xtend Prisma SSE protection to on-site users and connected devices, including IoT and OT systems. **Automated Connectivity:** Nile automatically establishes resilient IPSec tunnels from the Nile Service Block (NSB) to Prisma SSE, eliminating the need for external routers or manual configuration. **Built-in Resiliency:** Traffic is automatically rerouted to alternate Prisma nodes in the event of an SSE endpoint failure, ensuring uninterrupted service. **Policy-Based Traffic Steering:** Flexibly forward only selected segmented traffic to SSE for inspection. For example, employee traffic can be forwarded to SSE, but guest traffic can bypass SSE to reduce inspection load and cost. **Simple Management:** Admins simply enter Prisma credentials in the Nile Control Center. The rest—from tunnel setup to ongoing management—is fully automated.
      </Paragraph>
      <Paragraph>
        Ideal for organizations looking to adopt cloud-delivered security with minimal setup, reduced operational overhead, and maximum reliability.
